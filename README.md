# Romo7

Romo7 is an independent **AI + research + product** studio.

The work starts with real questions, tests ideas with evidence, builds useful tools, and looks for sustainable paths to value rather than adding AI for its own sake.

## Current focus

- **Research** — practical AI/tool evaluation, experiments, and evidence-led notes
- **Products** — small useful software built around real user needs
- **Persian language + AI** — language-aware tools and evaluation work
- **Automation** — repeatable workflows that reduce manual work
- **Revenue** — direct services, products, research work, and selective bounties with measurable value

Web3 is used selectively when it is relevant to a project or paid opportunity; it is not the core identity of Romo7.

## Projects

- **Romo Diary** — a private-first life-story app focused on simple daily capture, voice, media, and user-controlled legacy options
- **Podify** — text-to-audio/podcast tooling with multilingual and Persian support
- **PAIB** — Persian-first agent integrity benchmark for prompt injection, tool authorization, evidence reliability, and cross-lingual attacks
- **Romo7 research** — public notes, experiments, and product learnings

## Collaboration

Romo7 is open to research, product, and technical collaborations. When collaborators contribute materially to a revenue-generating project, the intended model is transparent, project-specific revenue sharing rather than unpaid contribution.

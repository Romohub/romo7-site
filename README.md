# Romo7 v3

A static multi-page personal site for Romo7: AI × Web3 × Creative.

## Pages
- `index.html` — home / live snapshot / proof of work
- `projects.html` — Romo Diary, on-chain research, automation, creative work
- `notes.html` — Field Notes and long-form research

## Identity asset
- `assets/romo-avatar.png` — original Romo pixel character reused from the user's existing asset library.

## Open locally
Extract the folder and open `index.html` in a browser.

## Deploy
Upload this folder to Vercel, Netlify, GitHub Pages, Cloudflare Pages, or any static host.
No build command, package manager, backend, database, or paid hosting is required.
